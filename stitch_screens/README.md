# Stitch Screens Catalog & UI Workflow

This directory archives visual references, AI-generated design iterations, and tracking for implemented views within PrepAura.

---

## Workflow: Reference -> Generated -> Implemented

PrepAura follows a 3-tier UI implementation progression:

1. **Reference (`reference/`)**: High-fidelity design mockups, wireframes, or design inspiration sources (e.g., Mobbin captures, claymorphic architectural references).
2. **Generated (`generated/`)**: Screen assets generated by Stitch MCP, image generation tools, or code generation runs prior to review.
3. **Implemented (`implemented/` / `src/pages/`)**: Fully functional React 19 JSX components styled with Tailwind CSS, tested, and mounted in the application router.

## Design System Tokens

All screens must adhere to the Modern Antique Claymorphic design system specified in [design-system.md](../docs/design/design-system.md) and [ui-guidelines.md](../docs/design/ui-guidelines.md).

- Zero emojis.
- Glazed porcelain cards with double bevel highlights.
- `Fraunces` serif headings and `Plus Jakarta Sans` body.
