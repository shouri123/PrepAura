Use the attached DESIGN.md as the primary design-system source of truth.
Use the attached 12-screen JPEG reference as the visual direction and overall composition reference. Recreate the same design philosophy, hierarchy, spacing, density, typography, and black/orange visual language, but do not blindly copy individual pixels or text from the reference.
Use the existing GitHub repository and live PrepAura website to understand the current functionality, routes, content structure, and user flows. Preserve existing functionality while redesigning the UI.
The target is a premium, production-quality SaaS application — not a generic AI dashboard and not a typical student project.
Prioritize:
- Minimal black/dark interface
- Restrained warm orange accent
- Strong typography
- Generous whitespace
- Thin borders and subtle surfaces
- Clear visual hierarchy
- Consistent components across all 12 screens
- Professional desktop and mobile layouts
IMPORTANT:
Do not add emojis.
Do not add unnecessary decorative symbols.
Do not add random icons simply to fill space.
Do not introduce unnecessary illustrations, blobs, glowing effects, excessive gradients, excessive glassmorphism, or excessive shadows.
Do not make every section a card.
Do not overuse orange.
Orange should primarily communicate action, focus, progress, selection, and important information.
Treat the 12 screens as one cohesive product and design system rather than twelve independent pages.
Preserve the existing route structure and functionality. Improve the visual design, UX hierarchy, spacing, responsiveness, and consistency without removing useful features.
When the reference image and existing implementation differ, prioritize:
1. Existing functionality and user flow
2. DESIGN.md rules
3. Visual direction of the reference image
Make the final result feel like a mature commercial product with the restraint of Linear/Vercel-style interfaces while retaining a distinctive PrepAura identity.
