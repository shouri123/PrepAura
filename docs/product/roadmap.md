# Product Roadmap: PrepAura

## Phase 1: Core Calibration Chamber (Current Release)

- Full-fidelity simulation setup chamber with role, seniority, and rigor tuning.
- Real-time audio telemetry visualizer via Web Audio API.
- Four-vector evaluation scoring engine (Technical Rigor, Structured Delivery, Problem Decomposition, Edge-Case Conviction).
- Post-session executive debrief with question-by-question model answers.
- Modern Antique Claymorphic design system across all views.
- Dual-mode authentication (FastAPI SQLite backend with graceful client fallback).

## Phase 2: Real-Time Bidirectional Voice & WebSockets (Target: Q1)

- **Bidirectional Audio Streaming**: Replace text transcription polling with full-duplex WebSockets audio streaming to LLM voice endpoints.
- **Interviewer Interruptions**: Calibrated voice interruptions when the candidate rambles, strays from requirements, or proposes unscalable architectures.
- **Latency Diagnostics**: Real-time display of response latency and vocal pitch modulation telemetry.

## Phase 3: Multi-Agent Interview Panels (Target: Q2)

- **Panel Simulation**: Simultaneous multi-agent panels comprising:
  - The System Architect (drills into storage bottlenecks and consistency models).
  - The Product Manager (drills into business KPIs and user latency SLAs).
  - The Bar Raiser (drills into team leadership, culture, and operational failures).

- Cross-examination dynamics where agents challenge candidate contradictions.

## Phase 4: Collaborative Architecture Whiteboard (Target: Q3)

- Real-time interactive canvas (using Canvas API or Excalidraw integration).
- Candidates draw service boundaries, message brokers, caching tiers, and database clusters while speaking.
- AI dynamically parses canvas elements and critiques single points of failure in real-time.
